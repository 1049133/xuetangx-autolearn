# 学堂在线视频脚本：新版兼容修订 1.7.0

基于 [yang-kun-long/xuetangx-js](https://github.com/yang-kun-long/xuetangx-js) 的 1.6.2 修改，保留 MIT 许可证。这是由 1049133 维护的新版兼容 Fork，原作者仓库的在线安装链接仍是原版。

**[点击安装或更新脚本](https://raw.githubusercontent.com/1049133/xuetangx-js/main/userscripts/xuetangx-autolearn.user.js)** · **[下载 v1.7.0](https://github.com/1049133/xuetangx-js/releases/tag/v1.7.0)**

保留自动 **2 倍速、静音**及切换下一未完成视频；需在面板点击启动。

## 安装与使用

1. 已安装 Tampermonkey（油猴）时，可点击上方安装链接并确认安装或更新。若链接只显示代码，打开油猴管理面板，找到原脚本或新建脚本，进入编辑器。
2. 用 `userscripts/xuetangx-autolearn.user.js` 的**全部内容**替换原脚本，按 Ctrl+S 保存。不要同时启用两份脚本。
3. 刷新学堂在线课程页面，面板应显示版本 1.7.0，目录加载后会列出未完成且可学习的视频。
4. 选择起点，点击“从所选章节开始自动学习”。浏览器若阻止播放，请手动点一次播放器播放。
5. 点击“停止自动切换”可取消轮询及待执行的切章。当前视频保持原状态，可自行暂停；“重新扫描目录”也会停止自动切换。

## 适配内容

- 新版 `/learn/space/...` 知识点目录：识别 `[id^="unit-item-"].menu-content-item`，按 `.item-type` 选择视频，标题使用 `.item-name` 的 textContent，折叠目录仍可读取。
- 新版进度：识别 `.item-status .is-finish` 及 `.status-pie` 的 `--p` 百分比；99.99% 不会视作完成。锁定图标对应的单元不加入待播列表。
- 继续支持旧版 `.third` 下的 li 目录及 `.percentFull` 完成标记。
- 每两秒检查目录变化，支持页面异步加载，保留用户选择；目录或课程变化时停止自动切换。
- 使用原生 video 的 playbackRate 和 muted，不再点击容易变化的音量图标。
- 播放器加载期间等待，超过 90 秒停止提示；切章时等待旧视频源被替换，避免误把上一节的 ended 当作下一节已播放完。
- 只有原生 ended 状态成立才检查进度，不再提前一秒离开。临时切到其他视频刷新进度时暂停主轮询，最多重播三次。
- 增加停止和重新扫描按钮，停止时取消延迟回调；日志最多保留 60 行。

学习进度由平台记录，倍速、课程限制、逾期或交互要求可能影响记录，请以平台显示为准。作业、考试、图文需要自行完成。

## 验证范围

2026-10-28，在学堂在线新版课程页面读取 DOM，确认测试课程共有 68 个单元，其中 33 个视频；适配规则正确识别全部 33 个视频，未混入图文、作业和考试。新版公开前端目录组件确认：完成图标为 `is-finish`，非满进度为 `status-pie`，`--p = schedules[id] * 100`。

通过 JavaScript 语法检查和 10 项 jsdom 回归测试，覆盖新旧目录、折叠目录、进度边界、锁定过滤、异步加载、视频等待、切章旧源、停止取消回调及单视频重播。尚未在浏览器中安装修订版，也未验证一次完整播放后的服务器进度回传，不能据此保证平台记分结果。
